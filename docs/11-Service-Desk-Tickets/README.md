# Service Desk Ticket Portfolio

Eight recruiter-facing support cases reconstructed from troubleshooting completed in the Enterprise IT Support Lab.

> **Scope:** These are simulated Service Desk tickets from a personal lab. They demonstrate troubleshooting process, technical validation and documentation. They are not customer or employer production tickets.

| Ticket | Area | Outcome |
|---|---|---|
| [INC-001 — Account Lockout](INC-001-Account-Lockout.md) | Active Directory / Identity | Account diagnosed, unlocked and sign-in verified |
| [INC-002 — DNS Resolution](INC-002-DNS-Resolution.md) | DNS / Domain networking | Stale NAT record removed; correct DC resolution verified |
| [INC-003 — RBAC Access](INC-003-RBAC-Access.md) | SMB / NTFS / AD groups | Sales access confirmed; HR/IT restriction validated |
| [INC-004 — Failed Authentication](INC-004-Failed-Authentication.md) | Event Viewer / Security | Event 4625 investigated and attributed |
| [INC-005 — M365 Password & Sign-in](INC-005-M365-Password-SignIn.md) | Microsoft 365 / Entra ID | Password reset and sign-in logs validated |
| [INC-006 — M365 Service Plan](INC-006-M365-Service-Plan.md) | Licensing / Application access | Forms service restored |
| [INC-007 — Exchange Mail Flow](INC-007-Exchange-Mail-Flow.md) | Exchange Online | Two-way internal mail flow validated |
| [INC-008 — Intune Compliance](INC-008-Intune-Compliance.md) | Intune / Endpoint | Firewall state investigated; compliance restored |

## Workflow demonstrated

**User report → triage → investigation → root cause / interpretation → resolution → validation → documentation**

The tickets reuse the original screenshot evidence stored in the technical sections instead of duplicating image files.
