# INC-006 — Microsoft 365 Application Access / Service Plan

**Status:** Resolved  
**Category:** Microsoft 365 / Application Access  
**Priority:** P3 — Medium  
**Environment:** Microsoft 365 Business Premium

> Simulated Service Desk ticket reconstructed from troubleshooting completed in this personal lab.

## User report
A test user could not access Microsoft Forms.

## Investigation
The user's Business Premium licence and individual application/service-plan assignments were reviewed.

## Root cause
The Microsoft Forms service plan had been disabled as part of a controlled troubleshooting scenario.

## Resolution
The required Forms service plan was restored.

## Validation
Microsoft Forms access was restored.
